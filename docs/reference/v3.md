# v3 preview reference

The [Conversational AI v3 preview guide](../guides/v3-preview.md#low-level-reference-all-32-operations) lists the exact Go arguments, response body type, and condition headers for all 32 API operations. It also shows cursor iteration, ETag handling, and `PreconditionFailedError.Latest(ctx)`.

The `v3` package is handwritten against the repository-root `openapi.json` / `openapi.yaml` snapshot and protected by `.fernignore`. It is separate from the generated v2 clients in the [root SDK reference](../../reference.md). The Go module still uses `/v2` as its semantic major version.

| Go surface | Core types | Operation count |
|---|---|---:|
| `c.V3.Agents` | `AgentCreate`, `AgentPatch`, `Agent`, `AgentListItem` | 5 |
| `c.V3.Secrets` | `SecretCreate`, `SecretUpdate`, `SecretReplace`, `SecretKeyWrite`, `SecretKeyOptions`, `SecretSet` | 8 |
| `c.V3.Numbers` | `NumberCreate`, `NumberPatch`, `Number`, `SipTrunk` | 5 |
| `c.V3.Sessions` | `SessionStartRequest`, `SessionStartEphemeralRequest`, `SessionListOptions`, `SessionPatch`, `Session` | 6 |
| `c.V3.Campaigns` | `CampaignCreate`, `CampaignPatch`, `Campaign`, `CampaignSchedule` | 8 |

Every operation returns `(*v3.Response[T], error)`. The response contains `Body`, detached raw `Header http.Header`, `ETag`, `RequestID`, and `StatusCode`; list bodies use `v3.Page[T]`. `agentkit.Agent.Save` creates a stored agent and returns `*agentkit.SavedAgent`; `SavedAgent.Update` updates its configuration with an ETag guarded patch. That handle adds `AssignNumber`, `UnassignNumber`, and a project-wide `ListNumbers` scan. `AgoraClient.Secrets`, `AgoraClient.Numbers`, and `AgoraClient.Campaigns` expose project resources without requiring the versioned low-level namespace. The [workflow and compatibility sections](../guides/v3-preview.md#agentkit-workflows) explain their limits.

## Errors

Every v3 error belongs to one category, matched with `errors.Is` on a sentinel or `errors.As` on a type; all of them implement `v3.Error` (`Category() error`). See the [v3 preview guide](../guides/v3-preview.md#errors) for an example.

| Sentinel | Type | Fields and methods |
|---|---|---|
| `ErrValidation` | `*ValidationError` | `Message`, `Err` (cause); returned before any HTTP request |
| `ErrConfiguration` | `*ConfigurationError` | `Message`, `Err` (cause); invalid base URL, missing App ID, or invalid credentials |
| `ErrConnection` | `*ConnectionError` | `Err` (transport or body-read error), `Timeout() bool` |
| `ErrTimeout` | `*ConnectionError` | Subtype of `ErrConnection` for timeouts and expired deadlines |
| `ErrAPI` | `*APIError` | Non-2xx responses and 2xx responses that violate the API contract. `StatusCode`, `Header`, `Body []byte`, `ParsedBody any`, `Detail`, `Reason`, `RequestID`, `Err` (the `*core.APIError` for non-2xx, the violation for 2xx, or nil). `ContractViolation(resp, cause)` builds one from a `*Response[T]`. |
| `ErrPreconditionFailed` | `*PreconditionFailedError` | Subtype of `ErrAPI` for 412; `Cause` (the `*APIError`), `Latest(ctx)` |
