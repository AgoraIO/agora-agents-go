# v3 preview reference

The [Conversational AI v3 preview guide](../guides/v3-preview.md#low-level-reference-all-20-staging-operations) lists the exact Go arguments, response body type, and condition headers for all 20 staging operations. It also shows cursor iteration, ETag handling, and `PreconditionFailedError.Latest(ctx)`.

The `v3` package is handwritten against the staging OpenAPI snapshot and protected by `.fernignore`. It is separate from the generated v2 clients in the [root SDK reference](../../reference.md). The Go module still uses `/v2` as its semantic major version.

| Go surface | Core types | Operation count |
|---|---|---:|
| `c.V3.Agents` | `AgentCreate`, `AgentPatch`, `Agent`, `AgentListItem` | 5 |
| `c.V3.Secrets` | `SecretCreate`, `SecretUpdate`, `SecretReplace`, `SecretKeyWrite`, `SecretKeyOptions`, `SecretSet` | 8 |
| `c.V3.Numbers` | `NumberCreate`, `NumberPatch`, `Number`, `SipTrunk` | 5 |
| `c.V3.Sessions` | `SessionListOptions`, `Session`, `SessionAnalysis` | 2 read-only |

Every operation returns `(*v3.Response[T], error)`. The response contains `Body`, `ETag`, `RequestID`, and `StatusCode`; list bodies use `v3.Page[T]`. `agentkit.Agent.Deploy` creates or updates a stored agent and returns `*agentkit.DeployedAgent`. That handle adds `AssignNumber`, `UnassignNumber`, and a project-wide `ListNumbers` scan. The [workflow and compatibility sections](../guides/v3-preview.md#agentkit-workflows) explain their limits.
